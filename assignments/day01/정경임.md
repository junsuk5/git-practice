## 2. 가장 멘붕이었던 순간 & 트러블슈팅
- **문제 상황**: 처음 README.md를 add했을 때 터미널에 warning 문구 발생.
    - 문구 -> warning: in the working copy of 'README.md', LF will be replaced by CRLF the next time Git touches it
    - git config list에서 분명 core.autocrlf=true라고 적힌 것을 확인했는데 CRLF가 포함된 warning 문구가 뜨자 대충 보고 당황함.
- **원인 및 해결**: 문제는 아니었고, 윈도우라 CRLF를 LF로 대체한다는 안내 문구였음. warning 단어만 보고 당황했으나 별일 아니었음. 당황하지 말 것.
