## 1. 오늘 내가 직접 손으로 치며 배운 점

- `==` 연산자와 `equals()` 메서드의 차이를 재인지하였다.

```java
String inputPassword1 = new String("pass");
String inputPassword2 = new String("pass");

String message = (inputPassword1 == inputPassword2) ? "Pass" : "Oops";
System.out.println(message);
```

[실행 결과]

```text
Oops
```

## 2. 가장 멘붕이었던 순간 & 트러블슈팅

- 자바 파일 실행 시 한글 깨짐 발생
  - `java -Dfile-encoding=UTF-8 <파일명>.java` 결과 확인
  - 시스템 인코딩을 UTF-8로 설정

## 3. 나만의 언어로 재해석한 핵심 용어 사전

- `==`: 두 대상의 메모리 주소값(참조) 비교
- `equals()`: 두 객체의 값(내용) 비교
