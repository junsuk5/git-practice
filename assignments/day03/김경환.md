## 3. 나만의 언어로 재해석한 핵심 용어 사전

## 4. 의외로 배운점
- const, let 이 타입스크립트에서 헷갈렸었는데, 상수 변수 정리하면서 const와 let의 차이에서
  한번 할당하면 고정되는 const와  재할당해서 let은 값을 변경가능하단걸 헷갈리지 않게됨.
- 물론 var는 버그 투성이이므로 최대한 안쓰고 구현하면 좋을것 같음. 재할당, 재선언 등 꼬이는 경우 다수 발생.

- let score = 80; // 변수 선언 및 초기화 -> 메모리에 넣겠다.
score = 95;     // 재할당 (80 -> 95로 값 변경)

- const score = 90; -> 메모리에 넣고 이제 변경안됨.
score = 95; // 불가능
